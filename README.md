# Human Activity Recognition Using Smartphones

A machine learning project for classifying human activities using smartphone sensor data, with comparative analysis of baseline Logistic Regression and PCA-based dimensionality reduction approaches.

## Overview

This project uses the UCI Human Activity Recognition (HAR) Dataset to classify six different human activities based on accelerometer and gyroscope sensor data from smartphones. The study compares the performance and efficiency trade-offs between full-feature and dimensionality-reduced models.

### Activities Classified
- WALKING
- WALKING_UPSTAIRS
- WALKING_DOWNSTAIRS
- SITTING
- STANDING
- LAYING

### Key Results

| Model | Features/Components | Test Accuracy | Feature Reduction |
|-------|---------------------|---------------|-------------------|
| **Baseline (no PCA)** | 561 features | **98.25%** | - |
| **PCA(200)** | 200 components | 97.77% | 2.8x smaller |
| **PCA(104)** | 104 components | 97.14% | 5.4x smaller |

The baseline Logistic Regression model achieves the highest accuracy (98.25%), while PCA-based models trade minimal accuracy loss (<1.5%) for significant computational efficiency gains.

## Dataset

The [UCI HAR Dataset](https://archive.ics.uci.edu/ml/datasets/human+activity+recognition+using+smartphones) contains sensor readings from 30 volunteers (aged 19-48) performing six activities while wearing a Samsung Galaxy S II smartphone on the waist.

**Dataset Characteristics:**
- **Subjects:** 30 volunteers
- **Sensors:** 3-axial accelerometer and gyroscope
- **Sampling Rate:** 50 Hz
- **Total Samples:** 10,299 activity recordings
- **Features:** 561 time and frequency domain features
- **Window Size:** 2.56 seconds with 50% overlap (128 readings/window)

**Feature Types:**
- Time-domain statistics (mean, std, median, IQR, entropy, etc.)
- Frequency-domain features (FFT coefficients, spectral energy, etc.)
- Accelerometer features: 345 features
- Gyroscope features: 213 features

## Installation

### Prerequisites
- Python 3.8 or higher
- pip package manager

### Setup

1. Clone this repository:
```bash
git clone https://github.com/batuhne/Human-Activity-Recognition.git
cd Human-Activity-Recognition
```

2. Create a virtual environment (recommended):
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Download the UCI HAR Dataset:
   - Download from [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/human+activity+recognition+using+smartphones)
   - Extract to project root as `UCI HAR Dataset/`

5. Generate processed data:
```bash
python src/prepare_data.py
```
This creates the `outputs/processed/` directory with standardized `.npz` splits and `feature_groups.json`.

## Usage

### 1. Data Preparation

The `prepare_data.py` script processes the raw UCI HAR Dataset:

- Loads raw sensor data and labels
- Applies StandardScaler normalization (zero mean, unit variance)
- Creates stratified splits (70/10/20 and 80/10/10)
- Saves processed data to `outputs/processed/*.npz`
- Generates feature groupings in `feature_groups.json`

> **Note:** The `outputs/processed/` directory is not included in the repository due to file size. You must run `python src/prepare_data.py` after cloning to generate these files before using the notebook.

### 2. Analysis and Model Training

Open the Jupyter notebook for interactive analysis:

```bash
jupyter lab notebooks/PCA_LogReg_HAR.ipynb
```

The notebook includes:
- **Baseline Model:** Logistic Regression on full 561-feature space
- **PCA Analysis:** Variance analysis and component selection
- **PCA Models:** Performance evaluation with reduced dimensions
- **Comparison:** Accuracy vs. efficiency trade-offs
- **Visualizations:** Confusion matrices, variance curves, and performance plots

## Methodology

```
        ↓

    ┌───┴───┐
    │       │
Baseline    PCA Transformation
    │       │
    │   Dimensionality Reduction
    │       │
    └───┬───┘
        ↓

        ↓
Activity Classification (6 classes)
```

### Approaches

**1. Baseline Approach (No PCA)**
- Multinomial Logistic Regression with all 561 features
- L2 regularization to prevent overfitting
- Achieves highest accuracy (98.25%)
- Best for maximum classification precision

**2. PCA-Based Approach**
- Principal Component Analysis for dimensionality reduction
- Two configurations tested:
  - **PCA(104):** Retains 95% variance, 5.4x feature reduction
  - **PCA(200):** Empirically optimal, 2.8x feature reduction
- Minimal accuracy loss (<1.5%) for significant efficiency gains
- Suitable for resource-constrained deployments

### Data Preprocessing
- **StandardScaler** normalization for zero mean and unit variance
- **Stratified splitting** to maintain class balance across train/val/test sets
- **Subject-wise partitioning** (not random) for realistic generalization testing
- **Random seed 42** for full reproducibility

## Results and Analysis

### Performance Summary

The baseline model without PCA achieves the best test accuracy of **98.25%**, demonstrating excellent classification performance across all six activities. The confusion matrix shows strong diagonal dominance with minimal misclassifications, primarily between mechanically similar activities (SITTING vs STANDING).

PCA-based dimensionality reduction provides an attractive accuracy-efficiency trade-off:
- **PCA(200)** maintains 97.77% accuracy with 64% fewer features
- **PCA(104)** achieves 97.14% accuracy with 81% fewer features

### PCA Variance Analysis

The cumulative variance curve reveals that the 561-feature space contains significant redundancy:
- 90% variance captured by ~65 components
- 95% variance captured by 104 components
- 98%+ variance captured by 200 components

This redundancy arises from correlated sensor axes, temporal dependencies, and overlapping statistical measures across time and frequency domains.

### Practical Implications

| Use Case | Recommended Model | Rationale |
|----------|-------------------|-----------|
| **Maximum Accuracy / Benchmarking** | Baseline (no PCA) | Highest precision and recall across all activities |
| **Balanced Performance** | PCA(200) | Near-baseline accuracy with 2.8x efficiency gain |
| **Real-time / Embedded Systems** | PCA(104) | Compact model, 5.4x feature reduction, fast inference |

### Classification Insights

All models achieve consistently high performance (>95%) across all six activity classes:
- **Dynamic activities** (walking variants) are easily distinguished with near-perfect accuracy
- **Static postures** (sitting, standing, laying) show slight confusion between sitting and standing
- **LAYING** achieves perfect or near-perfect classification due to distinct sensor signatures
